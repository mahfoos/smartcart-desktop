# SmartCart POS for Windows and Mac

Downloads of the SmartCart POS till as an app. This repository holds only the installers; there's no code here.

| | |
| --- | --- |
| **Windows 10 or 11** | [Download SmartCart-POS-Windows.exe](https://github.com/mahfoos/smartcart-desktop/releases/latest/download/SmartCart-POS-Windows.exe) |
| **Mac** (macOS 11 or later, Apple silicon or Intel) | [Download SmartCart-POS-Mac.dmg](https://github.com/mahfoos/smartcart-desktop/releases/latest/download/SmartCart-POS-Mac.dmg) |

- **Windows:** run the downloaded file. If Windows says it protected your PC, choose *More info → Run anyway*.
- **Mac:** open the downloaded file and drag SmartCart POS into Applications. It's signed and checked by Apple, so it opens straight away.

Sign in with your shop ID, email and password, as on the web. Installed apps update themselves.

What the app adds to the till in a browser: bills print straight to the receipt printer, the cash drawer opens for cash, the customer display opens on the second screen, and it can start with the computer. Set these up under **Settings → Bill design → This Computer**.
